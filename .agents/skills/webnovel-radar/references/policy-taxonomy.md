# 政策分类与作者影响映射

## 一、分类

| 分类 | 典型内容 | 作者最关心 |
|---|---|---|
| 监管政策 | 出版管理、内容审核、未成年人保护、AI 生成内容标识、版权专项行动 | 什么能写、什么不能写、会不会影响上架 |
| 平台规则 | 签约、分成、稿费、全勤、保底、买断、审核、推荐、新书期、完结 | 钱怎么算、流量怎么给、会不会被限流 |
| 合同与版权 | 授权范围、期限、影视/有声/出海改编、解约、违约金 | 版权是不是卖断、能不能解约、收益怎么分 |
| 审核与处罚 | 违规判定、低质治理、AI 水文、抄袭融梗、下架封书 | 哪些红线不能碰、被处罚怎么办 |
| 流量与榜单 | 推荐机制、流量池、榜单规则、题材扶持 | 新书怎么起量、什么题材有流量 |
| 征文与扶持 | 大赛、训练营、新人计划、补贴、重点作品扶持 | 有没有奖金/保底/曝光机会 |
| IP 改编 | 短剧、影视、动漫、有声、出海 | 版权价值、改编机会、合同条款 |
| 作者生态 | 维权、抄袭争议、工作室、代写、跳槽、人物故事 | 行业风向、同类作者处境 |
| 行业数据 | 月活、营收、财报、市场份额、出海数据 | 平台稳定性、题材趋势 |

## 二、作者影响四问

每条政策/规则至少回答四个问题：

1. **影响谁**：全平台作者 / 新签约作者 / 已签约作者 / 某题材 / 某等级作者
2. **影响什么**：钱（稿费、分成、保底、全勤）、版权（授权、改编、解约）、审核（能不能写、会不会下架）、流量（推荐、新书期）
3. **什么时候**：发布日期、生效日期、截止日期、过渡期
4. **作者怎么办**：要不要改合同、要不要调整题材、要不要申诉、要不要备份、要不要关注后续

## 三、可信度分级

| 等级 | 来源 | 写法 |
|---|---|---|
| A 官方确认 | 新闻出版署、版权局、网信办、平台官方公告 | 直接陈述，标“官方” |
| B 平台公告 | 平台作家专区、帮助中心、公告页 | 标“平台公告”，保留原文链接 |
| C 权威媒体 | 中国作家网、正规行业媒体 | 标“媒体报道”，尽量找官方原文 |
| D 社区讨论 | 晋江论坛、龙空、贴吧、微博、小红书 | 标“社区来源/待确认”，不能当事实 |
| E 未证实传闻 | 无链接、无出处、匿名爆料 | 默认不写；确需写，放“待确认”，明确说明未证实 |

## 四、常见政策信号词

看到这些词要提高优先级：

- 签约、续约、解约、合同、授权、买断、保底、分成、稿费、全勤、税收
- 审核、违规、处罚、下架、封禁、低质、AI 水文、抄袭、融梗、洗稿
- 推荐、流量、榜单、新书期、完本、断更、字数
- 征文、大赛、扶持、训练营、补贴、重点作品
- 短剧、影视、动漫、有声、出海、IP
- 未成年人、内容安全、生成式 AI、标识、备案

## 五、写作口径

- **只做摘要**：不复述全文，不替代官方原文。
- **不制造焦虑**：不用“天塌了”“全完了”这类词；用“影响范围”“过渡期”“目前只针对 X”。
- **不替平台背书**：平台说“优化”，不等于作者收益一定变好；把变更点和影响分开写。
- **不替作者做法律判断**：合同/版权问题只提示“建议看原文/咨询专业人士”。
- **传闻降级**：社区爆料放“作者圈热议”，并标“待确认”；没有官方/权威媒体确认，不进头条。

## 六、示例：一条合格的政策条目

```markdown
   - 变化：新增“纯分成”签约模式，原保底模式保留但门槛调整。
   - 影响谁：新签约作者；已签约作者是否适用要看合同约定。
   - 作者怎么办：开新书前先确认签约模式；已签约作者查看后台通知或咨询编辑。
   - 生效/截止：2026-11-15 起执行。
   - 原文：https://...
```
